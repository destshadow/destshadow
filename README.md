## Progetto in evidenza

### [CantorDust++](https://github.com/destshadow/cantordust_cpp)

Strumento di visualizzazione e analisi di file binari sviluppato in C++. Integra nove modalità di rappresentazione, analisi dell’entropia, parsing delle sezioni ELF e PE, curve di Hilbert e Z-order, classificazione statistica N-gram e rendering tridimensionale.

Il progetto nasce come implementazione autonoma ispirata al lavoro originale di Christopher Domas ed è orientato all’analisi visuale, al reverse engineering e alla ricerca di pattern e anomalie nei dati binari.
